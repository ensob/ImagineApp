# ImagineApp

Small static demos for generating imaginative/digital art in the browser.

Run locally:

```powershell
# from repository root
python -m http.server 8000
# then open http://localhost:8000/digital_art_generator.html
```

Files of interest:
- `digital_art_generator.html` — main interactive demo and `ArtGenerator` implementation.
- `imaginative_art_generator.html` — alternate demo with particles and canvas.
- `index.html` — landing page and simple idea generator.

Notes
- No build step required. Use a static server to test.
